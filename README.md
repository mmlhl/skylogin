# 光遇账号登录器 (skylogin)

**官服、渠道服都能登，多开随便开。** 光·遇 PC（网易 ma75）的免扫码登录器：

- **支持的账号**：华为渠道、网易官方（官服）、B站、4399、vivo、九游——扫码 / 手机号验证码 / 账号密码都行
- **多开**：数量不限，每账号一个客户端，窗口自动排列，带监控墙
- 单文件 exe，**免安装**；不装证书、不改 hosts、不开代理、不注入游戏进程

## 它是怎么工作的

光·遇 PC 由「发烧游戏平台」启动，游戏启动后向平台要一张一次性票据才能进大厅。
这个工具**扮演那个平台**：收到游戏的索票请求（op13），用你已登录的账号签一张票
回给它（op14），游戏正常进入——对游戏来说和官方平台启动没有区别。

## 记住渠道：进游戏不再问 iOS / 安卓

官服（网易账号）每次进游戏都会问一句"你玩 iOS 还是安卓"。给账号记一个「游戏区」，
之后启动就按它签发，游戏直接进对应的区。

**原理只有一句话**：选区不是写在票里、也不是存在本地库，而是 `uni_sauth` 请求里的
`platform` 声明（`ad` 安卓 / `ios` / `hm` 鸿蒙）。声明什么，服务端就把这次登录记成哪个区。

**目前有两条已验证的路：**

1. **游戏身份 + 账号级凭证（`sa=-9` / `-99`）**：全自动，不需要手机，是当前产品采用的方式。
2. **平台登录 + 手机扫一次码**：平台身份登录后声明渠道，建码后用手机扫码确认，也能免选区
   （2026-11-09 实测成功）。代价是需要人拿手机扫一次。

| 怎么来的 | 凭证 | 能否免选区 |
|---|---|---|
| 账号密码登录（游戏身份） | 游戏 `sa=-9` | ✅ |
| 手机验证码登录 | 游戏 `sa=-99` | ✅ |
| 平台登录后手机扫码确认 | 游戏 `sa=3` | ✅ 需扫一次码 |
| 平台登录后自行确认（`confirm_login`） | 游戏 `sa=3` | ❌ 1306 |
| 扫码 | 游戏 `sa=-4` | ❌ 真机会弹选区 |

> 扫码的**渠道**由扫码设备上报的 `app_channel` 决定（华为手机→`huawei`），
> 写进寄宿槽后由槽位票继承；槽位票不带 `scp`，换票阶段改不了。
> 安卓设备扫→安卓区，iOS 设备应为 iOS 区（未实测）。

三个容易踩错的点：

- **`uni_sauth` 返回 200 不等于整条链路完成**，还必须有人把授权真正交给这个码。
- **确认有两条路**：自己拼 `confirm_login`，或让手机扫码。前者只接受游戏身份的账号级凭证
  （会话级 1306、平台身份 1424）；后者接受会话级凭证，所以平台登录也能靠它免选区。
- **`sa=3` 能启动游戏、能滚动续期，也能配合手机扫码免选区**，只是不能被 HTTP 冒充确认。

想细看链路、实测数据和代码位置，见 [docs/渠道记忆.md](docs/渠道记忆.md)。

## 怎么用

1. 双击 `skylogin.exe`（弹 UAC 点「是」）
2. 点「＋ 添加账号」：选渠道，扫码 / 收验证码 / 输密码
3. 选中账号，点「启动光遇」

之后每次只要：双击 → 点启动。**凭证长期有效**（账号级凭证 + 启动时自动刷新），
不需要反复扫码；中途关掉登录器再打开，运行中的游戏照样识别。

## 多开

多选账号 →「多开」，一次拉起全部：

- **数量不限**（按机器性能来）；第 2 个起从镜像目录启动——硬链接不占额外磁盘，客户端全退出后自动清理
- **窗口排列**：平铺网格，或堆叠四种方案（双摞 / 两行横向 / 两列竖向 / 满扇形）随你切换；
  多开弹窗里选，监控墙顶栏一键重排；等客户端站稳了才动窗口（不干扰启动，防闪退）
- **每个客户端独立设置**：窗口模式 + 画质（省电 / 默认 / 高画质 / 最高）+ 帧率（30 / 60 / 120）启动前写好
- **监控墙**：所有客户端缩略图一屏监控，点哪个切哪个，顶栏直接重排 / 强停
- 登录中的渠道弹窗会跟着自己的客户端一起移动，多个号并行登录互不干扰

多选账号还有批量条：全选 / 反选、批量启动 / 停止 / 删除。

## 账号与安全

- 凭证（token）长期有效，界面随时可手动「刷新凭证」；失效会弹提示
- 用「账号密码登录」并在本工具里直接输入密码时，密码用 **Windows DPAPI 加密**保存，
  凭证过期后会自动重登，不用你手动刷新（详见 [docs/无头登录与续期.md](docs/无头登录与续期.md)）
- 所有凭证文件（账号、token、设备指纹）用 **Windows DPAPI 加密存储**——
  绑定当前 Windows 用户，拷走文件也读不出内容
- 启动期间有客户端闪退会弹窗告知原因和补救方法

## 环境要求

- Windows 10 / 11 **64 位**（游戏本体即 x64）
- 界面用系统自带的 WebView2 运行时（Win11 全系自带；Win10 若界面打不开，
  装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) 即可）

## 架构

Go 单进程 + 内嵌 WebView2 界面（Vue 3），前端产物 `go:embed` 打进 exe；
界面和主进程只走本机回环 HTTP（127.0.0.1 随机端口）。

```
┌─────────────────────────────┐
│ WebView2（内嵌 Vue 3 界面） │
└──────────────┬──────────────┘
               │ HTTP，仅 127.0.0.1（随机端口）
┌──────────────▼──────────────────────────────────┐
│ Go 主进程                                        │
│  ├─ app        业务流程：账号 / 登录 / 取票 / 多开│
│  ├─ huawei     华为扫码换票                      │
│  ├─ netsec     SAUTH 构造 + HMAC-SHA256 签名     │
│  ├─ mpay       MPay 建码 / 短信 / 取票           │
│  ├─ mpayhost   子进程加载官方 mpay.dll（密码窗口）│
│  ├─ fever      冒充发烧平台：窗口 + op13/op14 IPC │
│  └─ win        提权 / 窗口排列 / 监控墙 / 托盘   │
└──────────────┬──────────────────────────────────┘
               │ 本地窗口消息（WM_COPYDATA）
┌──────────────▼──────────────┐
│ 光·遇 PC（sky.exe，管理员） │
└─────────────────────────────┘
```

技术要点：

- **纯 Go，`CGO_ENABLED=0`**：单文件分发
- **不用注入**：和游戏只通过平台窗口协议（op13/op14）交互；密码登录是唯一
  加载 `mpay.dll` 的地方，放在独立子进程里，崩了不影响主界面
- **凭证加密**：DPAPI（系统按当前用户管理密钥，工具自身不保存任何口令）

## 开发

```powershell
cd web && npm ci && npm run build && cd ..     # 前端产物打进二进制
go build -trimpath -ldflags "-s -w -H=windowsgui" -o skylogin.exe ./cmd/skylogin
go test ./...
```

| 模块 | 作用 |
|---|---|
| `internal/app` | 业务流程：账号、登录、取票、启动、多开、路由、状态恢复 |
| `internal/channel` | 渠道层：各渠道声明支持哪些登录方式，把登录结果包成统一凭证 |
| `internal/ucsdk` | 九游协议：RSA/AES 信封、手机号密码 / 验证码登录、滚动续期 |
| `internal/phone` | 机型库与设备标识生成（渠道无关） |
| `internal/device` | 设备档案：按「渠道 + 账号」绑定，DPAPI 加密存储 |
| `internal/huawei` | 华为扫码：取码 → 轮询 → 换 ST → 换 access_token → 游戏会话 |
| `internal/netsec` | SAUTH 构造 + HMAC-SHA256 签名 + `uni_sauth` |
| `internal/mpay` | MPay 建码 / 扫码 / 短信 / 取票 |
| `internal/mpayhost` | 账号密码登录：子进程加载官方 `mpay.dll` |
| `internal/fever` | 冒充发烧平台：窗口 + IPC + 镜像目录 |
| `internal/prefs` | 游戏设置文件（PREF 格式）读写：画质 / 帧率 / 窗口模式 |
| `internal/secretfile` | 凭证文件 DPAPI 加密存储 |
| `internal/web` | 本地控制面板（随机端口，仅 127.0.0.1） |
| `web/` | 前端（Vue 3 + Vite + TypeScript） |

发版走 GitHub Actions：推 `v1.2.0` 这样的标签会构建并创建 Release；普通 push 不构建。
