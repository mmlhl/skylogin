# 光遇账号登录器 (skylogin)

光·遇 PC（网易 ma75）× 华为渠道 / 网易官方账号 的免扫码登录器。
单文件 exe，不装证书、不改 hosts、不开代理、不注入游戏进程。

## 它做什么

光·遇 PC 由「发烧游戏平台」启动，启动后向平台要一张一次性票据。这个工具**扮演那个平台**：
收到游戏的索票请求（op13），用华为/网易账号换一张票，再回给它（op14），游戏就能进大厅。

因为没有中间人劫持，所以不需要证书、hosts、代理，也不占用 443。

## 怎么用

1. 双击 `skylogin.exe`（弹 UAC 点「是」）
2. 左边点「＋ 添加华为账号」或「＋ 添加网易账号」，手机扫码
3. 选中账号，点右边的大按钮「启动光遇」

之后每次只要：双击 → 点启动。扫过码就不用再扫，凭证会在启动时自动刷新。

### 账号列表

每个账号右侧常驻三个按钮：

| 按钮 | 作用 |
|---|---|
| ▶ / ■ | 启动这个账号的光遇 / 停止它 |
| 👁 | 单独切换明文显示（默认打码） |
| ⋯ | 修改别名、刷新凭证、删除 |

## 多开

点右下「多开」，勾选账号一次性启动。

- 前提是**当前没有光遇在运行**：游戏全局单实例，已经开着一个时新的会被它自己拦掉
- 数量不限；第 2 个起从镜像目录启动（硬链接，不额外占磁盘，退出后自动删除）
- 镜像目录必须和游戏同盘、且是空文件夹，设置里会校验

## 常见问题

**游戏卡在登录界面？** 票据没被接受，把 `%APPDATA%\SkyLogin\log.txt` 发出来。

**提示「发烧平台正在运行」？** 工具会自动结束它；失败就手动退出发烧平台再试。

**启动按钮是灰的？** 已经有客户端在运行，先点「停止运行」（或用多开一起启动）。

**数据存在哪？** 全在 `%APPDATA%\SkyLogin\`（账号、设备指纹），删掉即清除；不上传任何东西。

**会不会封号？** 只代替"平台发票据"这一步，不改游戏文件、不读写游戏内存。请自行判断，建议先用小号。

## 开发

```powershell
cd web && npm ci && npm run build && cd ..     # 前端产物打进二进制
go build -trimpath -ldflags "-s -w -H=windowsgui" -o skylogin.exe ./cmd/skylogin
go test ./...
```

| 模块 | 作用 |
|---|---|
| `internal/app` | 业务流程：账号、扫码、取票、启动、多开、路由 |
| `internal/huawei` | 华为扫码：取码 → 轮询 → 换 ST → 换 access_token → 游戏会话 |
| `internal/netsec` | SAUTH 构造 + HMAC-SHA256 签名 + `uni_sauth` |
| `internal/mpay` | MPay 建码 / 扫码 / 确认 / 轮询取票 |
| `internal/mpayhost` | 账号密码登录：子进程加载官方 `mpay.dll` |
| `internal/fever` | 冒充发烧平台：窗口 + IPC + 镜像目录 |
| `internal/web` | 本地控制面板（随机端口，仅 127.0.0.1） |
| `web/` | 前端（Vue 3 + Vite + TypeScript） |

发版走 GitHub Actions：推 `v1.2.0` 这样的标签会构建并创建 Release；普通 push 不构建。
