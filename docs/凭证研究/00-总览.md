# 扫码凭证研究 · 总览（大白话版）

## 一句话

**扫码加进来的网易账号，以后不用再扫了。**

## 先说说问题是什么

网易给我们的登录凭证有两种：

| 类型 | 打个比方 | 会不会过期 |
|---|---|---|
| **账号级** | 长期通行证，上面没写有效期 | 不会 |
| **会话级** | 临时通行证，写着"从哪天的什么时候起，能用一段时间" | 会 |

- 用**密码**或**手机验证码**登录 → 拿到长期通行证
- 用**扫码**登录 → 只给临时通行证

所以扫码加的号过几天就失效，用户以为"又要扫码了"。这就是这次要解决的问题。

## 我们找到了两个办法

### 办法一（主力）：临时通行证能自己续期

临时通行证上写着"从 X 时间开始"。我们拿它去换一次新的，**X 就变成现在了**，
等于把有效期重新开始算。

所以只要用户在过期前启动过一次登录器，我们就顺手换一次，一直有效。

```
拿旧通行证 → 换一张票 → 拿票再换一张新通行证（有效期从"现在"重新算）
```

**这个办法对所有扫码号都管用，不需要额外的东西。**

### 办法二（兜底）：让平台"记住"这个号

网易发烧平台有个"记住这个账号"的功能，记住之后可以**不扫码直接出票**。

我们发现：这个"记住"是跟着**平台账号**走的，而且**扫码时带上平台会话就会自动记住**。
以前我们扫码是"匿名"的，所以平台一直没记住。

现在扫码会带上平台会话，平台就会记住这个号。

## 两个办法的区别

| | 办法一 续期 | 办法二 记住 |
|---|---|---|
| 需要额外账号吗 | 不需要 | 需要（每个"记住位置"要一个能登录平台的号） |
| 能覆盖几个号 | **所有扫码号** | 每个位置一个号 |
| 什么时候用 | 平时每次启动 | 通行证真的过期了，救急 |

## 还有什么没搞清楚

有两件事只能靠"放几天/放两周"来观察，现在没法下结论：

1. 临时通行证的有效期到底是不是"从开始时间往后数固定天数"
2. 一直续期下去，会不会被服务端"续太多次"给掐掉

这两条写在 `03-猜测与待验证.md` 里，也写了怎么验。

## 一条容易踩的坑（已验证）

**同一个号在别的地方重新登录（尤其是用密码登），会把它之前所有的临时会话顶掉。**

我们做过实验：先滚出一条临时会话，再用密码登一次同一个号 →

```
密码登录后：拿到新的长期证 ✅
之前那条临时会话：1306 用户登录失效 ❌（被顶掉了）
```

所以"扫码号过几天就失效"，有一部分可能不是自然过期，而是用户在平台或别处登过一次。

想保住扫码号：别拿同一个号去别处登录；
真要用密码登也没关系——登完存的就是长期证，比临时证更稳。

**但"记住"不受这个影响。** 记在平台那边的号，重登多少次都还在，
只有"用同一个平台账号重新扫一次码"才会换掉。所以兜底这条路是可靠的。
## 渠道服扫码（2026-11-05 新增，实测结论）

**华为已打通**：游戏身份（ma75）开窗时，渠道服 App 也能扫，扫完能存成账号、能进游戏。
细节见 `04-渠道服扫码.md`。

但它**不是长期方案**，实测寿命：

```
扫一次 → 能反复启动约 1 小时 → 之后必须重扫
```

原因还是那个：渠道服扫码只给 `accessToken`（约 1 小时），拿不到华为的 ST，
所以没有能续期的根。定位：**临时加号**用。

顺带一个通用教训（已经写进代码）：

> **接口返回 200 不等于凭证还能用。**
> 华为的 getGameAuthSign 在 token 半失效时照样 200，只是响应里没有
> `ts` / `gameAuthSign`。只看"有没有报错"会把失效记成正常。
